# Jurniq Frontend Application

The modern web application for **Jurniq — AI-Powered Smart Mobility Platform**. Built with React 19, Vite, Tailwind CSS, Motion, and Socket.IO.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
